1. Adaptive Coverage Algorithms for Mobile Ad Hoc Networks in Dynamic Worlds

This paper extends an existing framework for the coordination of mobile agents in unknown worlds, by considering the possibility of dynamic instability. In the original problem, known as the Partially Observable Cooperative Guard Art Gallery Problem (POCGAGP) (arXiv:2512.09495), the multi-agent system must establish a communication network which completely covers an initially unknown constrained space. However, the POCGAGP fails to account for the unpredictability often seen in real-world deployment. To address this, the dynamic case (DPOCGAGP) introduces two settings which can influence the mobile network during deployment: Agent Loss and World Change, which represent dynamic changes to the world. Within this study, we present advancements to two state-of-the-art algorithms, the Centralized Agent-Directed Exploration for Network Coverage (CADENCE), and its decentralized analogue, DADENCE, to provide solutions in these cases. We then compare their performance against another state-of-the-art benchmark algorithm, and show that the adapted algorithms outperform across our benchmark test set, which comprises over 4500 test cases of varied size and structure.

2. ORION: An Outcome-Driven LLM Advisor for RL-Based Multi-Domain 6G Slice Placement

Deploying 6G network slices across administrative domains requires an online decision for each arriving request: which domain hosts each virtual network function, how traffic crosses domain boundaries, and whether the slice is admitted. This joint decision problem is NP-hard under continuous arrivals. Experiments on a parametrized family of multi-domain topologies show that no fixed planning strategy dominates across all regimes: the performance ranking reverses between topology classes, and feasible placements exist for most rejected requests but remain undiscovered. These findings identify the plan layer as the decisive performance lever. We introduce ORION, a hierarchical orchestrator in which two LLM agents translate service intents into structured requests and generate abstract placement plans. A cooperative multi-agent RL coordinator selects the cross-domain partition, treating the plan as a persistent soft prior, while per-domain agents place the functions. ORION main contribution lies at the plan layer: an outcome-driven episodic memory that records, for each completed attempt, the network-condition profile, the proposed plan, and its verified feasibility outcome. The memory feeds verified successes and labelled failures back to the planner, thereby closing the adaptation loop using deployment feasibility rather than a scalar reward assigned to the planner's own proposals. 4. ProSearch: Benchmarking Multi-Constraint Protocol Retrieval in Experimental Science

In AI for Science scenarios, experimental design and method reproduction require retrieving protocols that satisfy multiple interdependent constraints, yet existing benchmarks lack systematic evaluation of this capability. To address this gap, we introduce ProSearch, a benchmark for multi-constraint protocol retrieval in experimental science. ProSearch has three key features: (1) realism, with queries grounded in real experimental records and expert-defined templates; (2) complexity, with 60 experimental fields and their dependencies; and (3) diagnosticity, with 3-5 explicit constraints per query, including numerical and negation constraints. We construct ProSearch through LLM-based extraction, data-driven constraint selection, controlled query generation, and evidence-based relevance validation. The resulting benchmark contains 1,515 queries across six experimental science domains. We conduct extensive experiments on ProSearch with 19 representative retrievers and complementary analyses. The best-performing retriever achieves an average nDCG@10 of only 0.290, which improves to 0.474 with reranking. Structured diagnostic analysis shows that explicit constraint matching provides a strong ranking signal, while manual error analysis identifies joint constraint binding as a key bottleneck. ProSearch provides a testbed for systematically evaluating scientific retrieval systems.

5. Latent Reasoning in Continuous Space for Unified Multimodal Models

As a result, existing reasoning-augmented UMMs often fail to inherit the test-time scaling and fine-grained controllability observed in large language models. We attribute this failure to a fundamental modality mismatch: reasoning is performed in a discrete token space, whereas image generation operates in a continuous space. 统一多模态模型（UMMs）在多模态理解与生成任务上表现突出，却难以把基于语言的思维链推理有效用于图像生成，因此未能继承大语言模型上观察到的测试时扩展与细粒度可控性。论文把这一失效归因于模态错配：推理发生在离散 token 空间，而图像生成本身运行在连续空间。为此作者提出连续空间隐式推理框架 LARC，直接在连续隐状态上推理，以缓解 token 级瓶颈。训练分两阶段：课程式监督微调先把 token 级推理逐步转化为隐式推理，随后用信息增益强化学习在无真值监督下让隐式推理自我演化。在多个文生图基准上，LARC 在生成质量、提示词遵循与组合保真度上均稳定提升，并在 GenEval 上以较 BAGEL 高出 7 个百分点的成绩取得当前最优，同时在并行与串行两种测试时扩展下都优于基于 token 的生成；这意味着统一模型中理解与生成共享表征的瓶颈，或可由从离散语言推理转向连续表征的路径绕开。

把推理搬进连续隐空间，实质上让图像生成也能获得类似大语言模型的“思考预算”，这是对“文本 CoT 外挂”路线的正面挑战。但 7 个百分点的领先目前只体现在 GenEval 上，若连续推理无法在更通用基准稳定复现，这一范式大概率仍会停留在多模态生成的细分领域。

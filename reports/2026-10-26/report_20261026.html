1. Flownomaly: Single-Step Conditional-Mean Recovery for Few-Shot Anomaly Detection

Few-shot industrial anomaly detection requires modeling category-specific normality from only a handful of defect-free images. Common approaches tie inference to stored exemplars, impose rigid linear structure, or risk reproducing anomalous content. Flownomaly instead casts the problem as normal-counterpart recovery in frozen DINOv2 feature space. Given normal supports, a velocity field is learned through conditional flow matching over frozen patch tokens to transport Gaussian noise toward normal features. Along straight paths, a single recovery step using one evaluation of the optimal field yields the posterior mean of the clean normal token without trajectory integration. The operating time governs how strongly recovery modifies a query token. With no anomalous validation samples available for tuning, a normal-only Jacobian gain-to-noise criterion selects this time from the supports alone. Squared residuals between query tokens and their recovered counterparts yield anomaly signals for both dense localization and image-level detection. Across 1-, 2-, and 4-shot benchmarks on MVTec-AD and VisA, together with sample-shot evaluations on Real-IAD, Flownomaly achieves state-of-the-art performance against recent category-specific methods. In the 1-shot setting, image- and pixel-level AUROC reach 97.8% and 98.0% on MVTec-AD and 95.3% and 98.7% on VisA, with a 2.1-point image-level AUROC improvement over the strongest baseline on VisA. Code is available at https://github.com/b-rbmp

2. Green Code or Costly Code? Evaluating the Energy Costs of Iterative LLM-Based Code Optimizations

Large Language Models (LLMs) are increasingly used to optimize code for performance. This practice often assumes that improvements in execution speed naturally translate into overall lower energy consumption. We challenge this assumption empirically by measuring whether performance-optimized code produced by LLM self-refinement pipelines is also energy-efficient relative to canonical human reference solutions, and whether the energy cost of the optimization process can be offset by subsequent execution-time savings. We evaluate 11 open-source models across four decoding configurations on all 1,000 problems of EffiBench, a state-of-the-art performance benchmark, while collecting per-process, hardware-level energy measurements throughout. Inference energy spans 0.79 to 8.68 MJ across model-variant pairs, which is roughly equivalent to the energy of 250 to 2800 GPT-4.1 queries. 4. Do "True" and "False" Add Up to One? Complement Consistency in LLM-Agent Opinion Simulations

In LLM-agent opinion simulations, each agent reports the probability that a claim is true after seeing its own previous probability and the probabilities reported by its neighbors, and that number becomes its state in the next round. If the number describes the agent's position rather than the sentence it was shown, then rewriting the claim as its complement and replacing every probability p with 1 - p should return the complementary answer, so the two reports should sum to one. We test this with three small open models: Qwen3-4B, Llama-3.2-3B and Gemma-3-4B. On 2,304 agent states taken from a running network simulation, Qwen's paired reports sum to 1.18 on average, and on 48 real fact-checking claims from AVeriTeC they again exceed one. A controlled benchmark of 24 worlds, each with exactly two possible outcomes, shows the same failure in all three models. 5. J-Comm: Jacobian-Guided Latent Communication between LLM Agents

Latent communication requires both an effective continuous reasoning process and an interface through which an external model can leverage its intermediate computation. We present J-Comm, a framework comprising two core components. First, a training-free Geometric Agreement for Latent Reasoning (GEAR) reweights token candidates over existing model embeddings, which monotonically optimizes geometric consensus among candidate tokens in embedding space at each step. Second, we introduce an H+J (Hidden-and-Jacobian) communication interface that gives the Receiver two complementary views of the Sender's reasoning. The H channel supplies continuous inputs derived from feedback distributions, while the J channel conveys intermediate-state cues in vocabulary-indexed Jacobian-lens coordinates. Intuitively, H provides inputs for the Receiver to reason from, while J offers additional guidance within its computation. The Receiver reconstructs these cues using its own dictionary and injects them into intermediate layers during prefill, enabling communication without sharing key-value caches or requiring identical model widths. In Qwen3-8B to Qwen3-4B communication, J-Comm achieves the highest mean score across seven benchmarks, including 94.80% on MATH500, 54.55% on GPQA-Diamond, 73.33% on AIME2024+2025, and 62.93% success on ALFWorld. Compared with TextMAS, it improves performance by 1.29-8.59 percentage points and reduces generated text tokens by 19.2-74.8%.

1. Flownomaly以单步条件均值恢复刷新少样本异常检测

Flownomaly 把少样本工业异常检测改写为冻结 DINOv2 特征空间中的正常对应物恢复问题：给定少量无缺陷支持样本，用条件流匹配在冻结 patch token 上学习速度场，将高斯噪声输运至正常特征分布，并沿直线路径仅做一次最优场求值即完成单步恢复，直接得到干净正常 token 的后验均值，无需轨迹积分。恢复时间决定查询 token 被改动的强度，在无异常验证样本可调的情况下，作者提出仅依赖正常支持样本的雅可比增益-噪声准则来选定该时间；查询 token 与其恢复对应物之间的平方残差同时产出用于稠密定位和图像级检测的异常信号。在 MVTec-AD 与 VisA 的 1-shot、2-shot、4-shot 基准以及 Real-IAD 的样本 shot 评测上，该方法对近期类别特定方法取得 SOTA：1-shot 下 MVTec-AD 图像级与像素级 AUROC 达 97.8% 与 98.0%，VisA 为 95.3% 与 98.7%，其中 VisA 图像级 AUROC 比最强基线高出 2.1 个百分点。该工作已被顶会录用（3 位作者），代码开源于 GitHub；其意义在于绕开推理阶段对存储样本的依赖与刚性线性结构，使少样本工业检测更贴近低延迟部署。

4. Do "True" and "False" Add Up to One? Complement Consistency in LLM-Agent Opinion Simulations

论文检验LLM-agent意见模拟中的补集一致性：智能体在读取自身先前概率与邻居报告的概率后，需要报告“主张为真”的概率，而这个数值会成为它下一轮的状态；如果该数值描述的是智能体立场，而不是它看到的句子，那么把主张改写为其补集、并将每个概率p替换为1-p后，两次报告应相加等于1。作者用Qwen3-4B、Llama-3.2-3B和Gemma-3-4B三个小模型测试：在一个运行中的网络模拟的2304个智能体状态上，Qwen的成对报告平均相加为1.18；在AVeriTeC的48条真实事实核查主张上也超过1；在24个各只有两种可能结果的受控世界基准中，三个模型均出现同样失败。该偏差比同义改写带来的变化大2至10倍，并在重复采样、不同同伴群体规模和报告强度下持续；当这些报告被反馈到两个从互补状态出发的群体时，五轮后所有模型的两个群体都出现正发散，不再保持镜像。把每个答案与其配对答案的补集做平均，可按构造恢复一致性，并降低按两种措辞平均的Brier损失，但在最后一轮，这并不总优于两种原始措辞中较好的那一种。若补集一致性不成立，模拟中的意见状态就可能混入措辞或框架效应，削弱LLM作为社会模拟主体的效度；对于基于LLM的多智能体意见动力学和依赖概率输出的决策系统，不变量、校准与复述鲁棒性检验可能比只看“输出是否合理”更关键。

5. J-Comm 用雅可比接口让 LLM 智能体在潜空间直接通信

该论文提出 J-Comm 框架，目标是在 LLM 智能体之间进行潜空间通信，从而绕开自然语言文本的离散瓶颈。框架包含两个核心组件：其一是无需训练的 GEAR（Geometric Agreement for Latent Reasoning），它在每一步对基于现有词嵌入的候选 token 重新加权，让候选 token 在嵌入空间中的几何一致性单调提高；其二是 H+J（Hidden-and-Jacobian）通信接口，为接收方提供发送方推理的两种互补视角——H 通道给出由反馈分布导出的连续输入，J 通道则以按词表索引的雅可比透镜坐标传递中间状态线索，接收方用自己的词典重建这些线索并在 prefill 阶段注入中间层，因此既不需要共享 key-value 缓存，也不要求两端模型宽度相同。在 Qwen3-8B 向 Qwen3-4B 的通信中，J-Comm 在七个基准上取得最高平均分，其中 MATH500 为 94.80%、GPQA-Diamond 为 54.55%、AIME2024+2025 为 73.33%、ALFWorld 成功率为 62.93%；与 TextMAS 相比，性能提升 1.29–8.59 个百分点，同时生成的文本 token 减少 19.2%–74.8%。这意味着多智能体协作的关键接口正从文本消息转向表示级通道；若后续在更多模型组合上成立，跨模型互操作的部署门槛将不再主要取决于是否需要额外训练对齐。

两处设计的选择很克制：GEAR 只在现有嵌入上重加权，H+J 只传线索而接收方用自身词典重建并注入中间层；这使得异构模型、不同宽度模型之间的协作不必再先做对齐训练或共享缓存，延迟敏感场景下的通信成本从生成长文本转向固定的表示注入。若该路径在更多模型组合上稳定，多智能体系统的性能瓶颈将更多落在表示能否互相解析，生成长度的影响会减小。

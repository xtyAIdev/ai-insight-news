### 2. Ollama 一套运行时跑通 Kimi、GLM、DeepSeek 等中外模型

Ollama 可让开发者快速上手运行 Kimi、GLM、MiniMax、DeepSeek、gpt-oss、Qwen、Gemma 及其他模型，同时覆盖国产开源模型与 OpenAI 开放权重模型两条线。该仓库目前在 GitHub 上累计 182,568 stars、18,179 forks，open issues 为 4,234。把这些模型收进同一个运行时，开发者无需为各家推理框架分别适配，就能做多模型本地部署与横向评测；对隐私敏感或成本敏感的场景，也提供了云端 API 之外的可行替代。这使本地推理工具从单模型运行器转向跨厂商的模型分发与推理标准化平台，开源模型生态的入口价值进一步向 Ollama 这类运行时集中。

### 5. headroom 在 LLM 入口压缩上下文，JSON 负载可省 60-95% token

headroom 是一款在工具输出、日志、文件和 RAG 片段进入 LLM 之前先行压缩的开源组件，提供 library、proxy 和 MCP server 三种形态。按项目给出的数据，它能让编码 agent 少用 20% 的 token，面对 JSON 类负载时 token 降幅达 60-95%，而答案保持不变。该仓库目前有 74,856 stars、5,805 forks，周增长约 552 stars，open issues 447 个。token 消耗是 agent 生产部署中最直接的可变成本与延迟来源，这套方案不换模型、不改提示词，只在上下文入口做减法，若压缩效果在实际负载中可复现，则它可能成为性价比很高的效率杠杆，也说明结构化数据整段投喂给模型的做法本身存在大量冗余。

> *JSON 这类结构化负载能被砍掉六到九成 token 而不损答案，暴露出当下上下文投喂方式的低效是结构性的，而非模型能力问题。若压缩、裁剪、缓存这类能力以 proxy/MCP 组件的形式被默认接入，上下文治理很可能继 MCP 统一工具接入之后沉淀为独立中间件品类，与模型能力提升并行成赛道。*

**时间**：2026-10-10

### 2. WOVEN用共享视觉转移原语统一解释MLLM四类推理缺陷

多模态大语言模型（MLLM）在空间、具身、物理和时序推理上表现不佳，论文假设这些失败源于视觉转移推理（visual transition reasoning）的共同缺陷，并检验它能否作为一套系统性训练配方下的共享训练原语，让不同模型从不同监督来源学习并跨任务复用。现有基准只是分别记录这些缺陷，不支持跨场景、动作与推理操作的受控比较；WOVEN 因此以视频预训练生成模型的多样化真实 rollout 组织转移监督，共 36,076 个样本，覆盖 20 种场景类型、5 种动作类型和 8 种推理类型。对 38 个前沿 MLLM（如 GPT-5.4 与 Qwen3-VL-235B-A22B）的评测显示，即便最强模型也远低于人类，且失败跨模型家族反复出现、随规模扩大依然存在。在 WOVEN 上按多种规模训练后，模型学到可广泛迁移的共享能力：每份仅约 2,000 条的多个训练子集合计把 26 个外部基准中的 22 个提升了最多 27.3 个百分点，WOVEN 数据还能替换某任务自身 30-50% 的训练数据而精度相当。若这一共享原语成立，多模态后训练的重心可能从堆叠任务数据转向构建共享的世界模型能力，具身与视频理解赛道的评测也需重新设计控制变量。

**时间**：2026-10-08

**标签**：cs.CV

**入选理由**：WOVEN 由 10 位作者合作，尝试把视觉世界建模织入多模态大模型，为多模态理解与世界预测的融合提供了一条新路径。

**来源**：[arXiv](https://arxiv.org/abs/2610.12417v1)

### 3. ViSkill 实现视觉原生技能与策略协同进化

技能增强型智能体通常把成功轨迹蒸馏为可复用策略以提升样本效率，但主流做法仍以文本为中心，把空间布局和动作—状态对应关系线性化为语言，从而丢失关键几何结构；少量引入视觉证据的工作又把技能构建与更新同策略优化割裂，二者相互促进的潜力未被充分挖掘。ViSkill 把成功交互编码为可直接被 VLM 智能体调用的复合视觉技能卡，检索到的技能同时指导推理与奖励塑形，成功轨迹再被蒸馏回技能库，形成技能积累与策略改进互相强化的闭环，并附带可选的冷启动机制加速早期学习。在 Sokoban、FrozenLake 与 PrimitiveSkill 上，ViSkill 总体成功率 0.89，加入冷启动初始化后升至 0.91，优于所评估的全部闭源与开源基线，收敛速度快于标准 PPO。代码地址为 https://github.com/ZJU-REAL/ViSkill。若这种技能库与策略在同一循环中互相改进的范式在 GUI/网页操作、具身操作与 VLM 智能体训练管线中成立，多模态原生技能表示可能逐步取代线性化文本，成为空间推理类智能体的默认技能形态。

### 4. VLM 最强仅 58%，SpaceCast-Bench 开测预测性空间推理

现有空间推理基准多只考察空间感知，即读取输入中已可见的关系，而真实空间智能需要预测性空间推理：从观察重建场景、预判干预如何改变场景、并对未见结果进行推理。为此，作者提出 SpaceCast-Bench，据其描述为首个直接且具诊断性地评估该能力的基准，围绕“观察—变换—推断”框架构建，包含来自 182 个真实场景的 3,862 道题，覆盖静态感知、局部预测、全局预测三个层级共 16 类任务，逐步要求场景理解、空间状态更新以及对未观察结果的关系推理。对 21 个模型的评测暴露出明显差距：最强模型仅达 58.0%，人类表现为 87.2%，而空间专用模型接近随机水平。控制分析进一步显示，bridge views 对整合分布式观察至关重要，显式 3D 证据比生成的结果图像或视频更稳定地帮助模型；在程序化生成数据上微调可将 Qwen3-VL-4B 从 34.0% 提升至 65.7%，并在六个域外基准上取得宏观平均增益。这也意味着多模态评测的标尺正从静态空间感知转向动态世界建模与因果预测，空间推理与具身智能、交互式规划的绑定会更深。

**时间**：2026-10-08

**标签**：cs.CV

**入选理由**：综合评分 3.6论文数据：作者数=8

**来源**：[arXiv](https://arxiv.org/abs/2610.12402v1)

### 5. Long Text to Predictive Features: LLM-Guided Blockwise Feature Engineering via Executable Program Search

> *论文提出 LLM-BlockFE：一个由 LLM 引导的离线特征构造框架，通过对长文本分块并搜索可执行程序，把非结构化文本转成结构化模型可直接消费的特征，而不必在实时推理时调用 LLM。*

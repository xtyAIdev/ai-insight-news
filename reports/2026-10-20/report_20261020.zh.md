### 2. NevIR重排评测：偏好判断正确却位置靠后的指标盲区

近乎相同的段落可能仅因否定等决定性条件不同而语义相反，重排器能把这样一对排对顺序，却仍可能把偏好段落压到检索列表的很靠后位置。作者用 dense、learned sparse 与 BM25 检索的固定候选池共同覆盖的官方 NevIR 成对样本检验这一差别：在 2,736 个 Test query directions 上，pairwise 训练的重排器把严格逐查询偏好从 52.30% 提升到 56.62%，但偏好段落 MRR 从 0.5764 降至 0.3055。一项带背景采样与修订监督的变体在固定模型 replay 中给出 MRR 0.5859、严格偏好 54.53%；对融合 top 20 做有界 pointwise 重排则两项同时改善——Qwen3-14B-AWQ 配融合 tie-breaking 达 77.45% 严格偏好、1,363 个完整对上 58.99% 的 NevIR 式配对准确率与 0.7509 的偏好段落 MRR，BGE cross-encoder 为 69.77% 与 0.7404。事后分析显示，两个指定段落获得相同 Qwen 评分、触发融合 tie-breaking 的分支占被评估方向的 27%，并包含了剩余严格偏好失败的大部分。作者据此主张将成对偏好、指定段落位置与计算成本放在一起评估，并把模型判断与整体排序流程区分开；这意味着混合检索后重排的稳健性无法只靠相关性或融合分数体现，若沿用传统指标，否定敏感检索中重排器的可靠性可能被高估。

> *成对偏好上升与偏好段落位置下沉同时出现，说明把 pairwise 排序器接进 RAG 混合*

**时间**：2026-10-19

**标签**：cs.IR

**入选理由**：这篇被顶会录用、由5位作者完成的论文，聚焦固定混合候选池中NevIR重排序评测，为检索排序研究提供方法学参考。

### 3. MixiSpeech: Progressive State Distillation for One-Step Vietnamese TTS

条件流TTS模型用较少采样步数即可获得较高合成质量，但把剩余轨迹直接压缩成单步更新仍会造成明显音质下降。MixiSpeech提出渐进状态蒸馏框架，在保留原有架构与说话人条件的前提下，把多步条件流声学模型转为单步生成器：它不直接训练单步模型，而是按10-4-2-1课程逐步压缩全局采样预算，每个学生模型用掩码状态匹配目标对齐局部教师积分的端点。该工作在PhoAudiobook上从零训练710说话人的越南语Matcha-TTS上实例化，在100组共享测试文本-说话人样本中，直接单步推理的UTMOS22-Strong仅1.6846、WER 6.21%，明显低于10步教师的2.2923与4.65%；经蒸馏的单步模型则达2.2678 UTMOS22-Strong、4.63% WER与2.83% CER，仅需一次声学向量场评估即找回单步操作点损失的大部分质量。端到端推理时间从10步教师的0.0662秒降至0.0312秒，实测加速2.12倍，说明渐进状态蒸馏可让单步条件流TTS在无需改动架构的情况下变得可用；若这一路线在更多语种上复现，直接压缩的是越南语TTS、端侧语音助手与实时配音的延迟与推理成本。

### 4. Agent 记忆几何特征预测检索失败：AUROC 0.640 且增益不显著

论文考察对话轮次、记忆文本与查询之间的几何关系能否在生成前预测答案正确性：作者评估了四种采用稠密或混合检索的记忆实现，并加入一个 observation-summary 对照，把这些文本嵌入同一空间，再用逻辑回归分类器基于描述查询接近度、记忆与对话对应关系、对话结构的 25 个特征做预测。在 LongMemEval-small 的 2367 个问题-系统对上，汇总 AUROC 为 0.640，低于 0.655 的问题难度基线；分题型看，几何特征在单会话助手（single-session-assistant）问题上达 0.841，但仅凭系统身份就已达 0.826。控制问题难度与系统身份后，几何特征并未带来统计上成立的汇总提升（delta = +0.002，95% CI [-0.010, 0.014]）。在固定存储的上下文选择实验中，按接近度排序的记忆比随机子集准确率更高，这与普通检索相关性一致；在 LoCoMo 上，最近轮次相似度对单跳问题有有限预测力，对其余若干类别则接近随机。训练使用正确性标签，预测仅用回答前特征且不额外调用 LLM 生成，作者据此强调，结果刻画的是记忆表示与正确性之间的关联，而非可直接部署的诊断——embedding 接近度并不能验证事实覆盖，也无法区分记忆构建差异；这意味着单靠几何信号在生成前可靠拦截记忆失败，目前证据仍不足。

**时间**：2026-10-19

**标签**：cs.CL

**入选理由**：该论文以7位作者规模获NeurIPS 2026录用，聚焦智能体记忆的几何结构，尝试预测检索受限的记忆失效并刻画其边界，为Agent记忆可靠性提供研究信号。

### 5. 多智能体强化学习做市切入Polymarket薄订单簿，报价与风控拆分解耦

论文研究在预测市场（以 Polymarket 为对象）用强化学习训练做市商：薄订单簿下逆向选择可能让基于真实数据训练的策略直接停止报价，一次报价的后果常常滞后多步才显现，而预测市场的 L2 数据又不包含仿真所需的单笔订单信息。作者从 Polymarket 重构出 LOBSTER 格式的订单级数据，在 JaxMARL-HFT 上用 417 个真实市场训练智能体，将订单簿与近期订单流补入观测空间，重设动作与库存控制，并提出把做市拆成“报价者 + 风险管理者”的协作式多智能体结构，以带 RNN 策略的循环 IPPO 训练。为缓解智能体之间的信用分配难题，论文考察了奖励混合与成交后 markout 等奖励塑形手段。结果显示，改造后的单智能体做市商报价更频繁、留出集损失低于重训的 JaxMARL-HFT 基线，但观测、动作与风险约束的联合改动各自贡献未被单独识别；仅做分解本身表现不佳，奖励设计是决定成败的关键变量。该工作已被 ICAIF 录用、由单人完成，其价值在于薄订单簿与事件驱动型市场的流动性供给有望得到更稳健的策略支撑。

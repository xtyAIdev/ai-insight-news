### 1. Hermes WebUI 提供网页与手机端 Agent 使用入口

仓库 hermes-webui 的定位是让 Hermes Agent 可以在网页或手机上使用，其自述称这是从 Web 端使用 Hermes Agent 的最佳方式。该项目社区数据为 19,363 stars、2,809 forks、940 个 open issues。Agent 框架的采用瓶颈常出现在交互层：CLI 门槛高、移动端不可用；Web UI 补齐后，Hermes Agent 的使用形态更接近可日常使用的客户端，上手与演示成本随之下降。这也意味着开源 Agent 的竞争点正从“模型+框架”向“框架+客户端体验”迁移，移动端适配或成为同类项目的默认要求，自托管用户与闭源 Agent 客户端之间的替代关系因此更值得观察。

## AI 学术研究

### 1. 手术多模态大模型压缩新解：SurgPace按复杂度渐进蒸馏

多模态大模型在机器人手术的问答、场景理解与具身辅助中潜力明显，但计算开销高，限制了临床实际部署，知识蒸馏因此成为构建紧凑手术模型的一条可行路径。然而直接蒸馏并不适配手术数据：样本在难度、视觉模糊度和所需临床语境上差异极大，统一的师生迁移不稳定；同时监督信号的作用会随训练推进而变化——早期需要更强的教师引导来完成多模态对齐，后期更依赖任务监督来有效优化。为此作者提出SurgPace，一个面向手术视觉语言模型的复杂度感知连续课程渐进蒸馏框架：它用预测置信度与Lorentz几何一致性估计样本复杂度，并以融合得分驱动连续的由易到难训练过程。方法进一步引入分层表示对齐，在特征、logit 与概率三个层面让学生对齐教师，同时把训练重心从模仿教师逐步转向任务监督，从而把样本级课程与目标级调度解耦，使蒸馏更稳定有效；评估在基于Surg-396K构建的基准上进行，该工作为顶会录用论文、共10位作者。把压缩从“统一拟合”推进到“按复杂度适配”，直接关系到手术多模态模型能否在临床实时性与算力约束下真正落地。

**时间**：2026-11-02

**标签**：cs.CV

**入选理由**：作为被顶会录用的10人作者团队成果，SurgPace聚焦手术多模态大模型，以复杂度感知的渐进式蒸馏压缩模型，为医疗多模态大模型落地提供轻量化训练思路。

**来源**：[arXiv](https://arxiv.org/abs/2611.03125v1)

### 2. VC-1K：千段真实手机视频通话素材补齐RTC评测盲区

论文提出开源测试集VC-1K（Video Conferencing 1000），包含约1000段视频序列，专门用于评测实时通信（RTC）场景下的视频处理与编码流水线。与主要依赖棚拍或屏幕内容的现有测试集不同，VC-1K由消费级移动设备采集的用户生成视频通话内容，以不同人脸的说话人（talking-head）序列为主，另含少量无人的后置摄像头外向视频，以覆盖更多常见RTC用例。数据横跨设备类型、光照条件、运动程度、室内外环境与人群多样性，且每段视频均配同步音频，便于多模态研究。论文详述了数据集的设计方法与统计分布，并在RTC典型分辨率、CBR编码下对OpenH264、SVT-AV1和libaom做对比评测，同时以RealESRGAN和GFPGAN两种超分方法验证其作为前后处理基准的可用性。由于现有测试集多来自棚拍或屏幕内容，难以反映移动视频通话在光照、运动、噪声和设备上的差异，VC-1K补上了真实UGC评测的盲区，使RTC编码与处理算法的比较更贴近端到端QoE。

**时间**：2026-10-30

**标签**：eess.IV

**入选理由**：VC-1K 作为面向实时通信的多样化视频测试集获顶会录用，5位作者参与，为RTC视频评测提供公开基准信号。

**来源**：[arXiv](https://arxiv.org/abs/2611.00192v1)

### 3. Preprocessing Choices in Fine-Tuning Data Matter: Utility and Demographic Sensitivity in LLM-Based Recommendation

生成式LLM推荐以文本描述用户历史与物品信息来产出推荐列表，但会带来输出有效性、prompt一致性以及对人口属性描述符敏感等问题；这项被CIKM 2026录用的三人研究考察微调数据的预处理选择如何影响推荐效用与公平性相关表现。作者搭建了受控推荐流程，组合监督微调、目录约束解码与prompt增强，并比较三类预处理选择：物品标题表示、人口属性平衡、辅助物品知识增强。MovieLens-1M实验显示，目录约束解码消除了目录外物品并保证完整的十条输出，prompt增强提升了prompt一致性与效用；改用原始MovieLens标题后HR@10由10.67%升至12.47%，Coverage@10由41.36%升至47.88%。公平性影响依属性而异：年龄平衡与知识增强在基本保持效用的同时缩小了所选群体层面的效用差距，性别平衡则降低效用却未改善所评估的性别相关指标。这意味着预处理不宜再被当作工程细节，当团队要同时审计效用与公平性时，数据管线本身就是可调节的设计变量。

**时间**：2026-11-02

**标签**：cs.IR

**入选理由**：综合评分 3.6论文数据：影响力信号=CIKM 2026 录用，作者数=3

### 4. SCOPE 以技能渐进探索改善长程 Web 智能体训练

大模型正把自主智能体推向真实环境，Web 是其中最具代表性的交互场景之一；但用朴素探索训练 Web 智能体并不容易：成功轨迹稀少，终端奖励稀疏，失败轨迹难以提供有效反馈。受技能习得理论启发，论文提出 Skill-Composed Progressive Exploration（SCOPE），把复杂任务探索拆解为由局部技能逐步扩展到完整任务求解能力的从短到长学习框架。SCOPE 围绕局部技能迭代推进：Skill Discovery 从历史 rollout 中抽取可复用的局部技能与失败经验，Skill Orchestration 将已发现技能组合为高层技能链，Skill Expansion 则借助与当前技能链对齐的失败经验引导智能体探索新的子技能；随后通过 agentic on-policy distillation 把逐步构建的任务完成技能链内化进策略参数。在 WebArena、WebVoyager 与 WebShop 上的实验显示，SCOPE 稳定改善探索动态，相对各设定下最强基线取得 3.9% 至 18.6% 的相对提升。该工作已被 NeurIPS 2026 录用（5 位作者），其技能分解思路为失败轨迹提供了更细粒度的学习信号，也意味着 Web 智能体训练可能不再只依赖端到端试错。

**时间**：2026-11-02

**标签**：cs.AI

**入选理由**：该论文获NeurIPS 2026录用，5位作者提出从局部技能到长程Web任务的渐进式技能探索，为LLM Web Agent提供可循路径。

**来源**：[arXiv](https://arxiv.org/abs/2611.03116v1)

### 5. MIRA 以欺骗性视觉上下文训练多模态推理鲁棒性

针对 RLVR 框架下多模态推理存在的“感知—推理鸿沟”——模型过度依赖看似相关的视觉 token，微小扰动会沿推理链放大为累积幻觉——论文提出训练框架 MIRA。该方法在训练中注入经过筛选的欺骗性视觉上下文，构造“hard traps”压测模型对误导信息的抵抗力，并引入 group-wise reflection-triggering 机制，让模型自主发现并纠正视觉线索与逻辑约束之间的不一致，最终内化为策略行为，且全程不依赖人工标注。该工作已被 NeurIPS 2026 录用（8 位作者），实验显示其在多个推理与感知基准上域内平均提升 7%，以视觉为中心的基准也取得一致改善，作者据此认为主动的错误恢复能力是稳健多模态推理的关键。这一思路把“抵抗错误上下文”本身变为可训练目标，补上了 RLVR 偏重答案正确性、却默认视觉输入可靠所留下的感知鲁棒性空白，对视觉问答、文档理解、图表解析等依赖视觉证据的下游任务更为直接相关。

**时间**：2026-11-02

**标签**：cs.CV

**入选理由**：8位作者的多模态推理论文MIRA获NeurIPS 2026录用，其以欺骗性上下文增强来强化多模态推理，为多模态推理训练提供了新的数据增强思路。

**来源**：[arXiv](https://arxiv.org/abs/2611.03087v1)

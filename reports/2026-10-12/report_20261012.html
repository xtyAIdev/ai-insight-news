1. QTestBench: A Test Framework for Evaluating LLM-Generated Quantum Code

Large language models (LLMs) have shown strong results in classical code generation and are increasingly used to write the unit tests that safeguard that code. Whether they can do the same for quantum software is less clear, because quantum programs are probabilistic, depend on numerical tolerances, and are judged by domain-specific checkers, so a well-formed test can still disagree with the benchmark's verdict. Existing quantum benchmarks measure whether a model produces a correct solution, but not whether its tests can distinguish correct implementations from faulty ones. We introduce QTestBench, a framework that evaluates LLM-generated quantum test suites against independent benchmark checkers, never treating the tests themselves as ground truth. For each task, QTestBench prompts models to produce syntactic, semantic, and behavioral tests, injects candidate solutions at runtime, and compares each test verdict with the checker's label under three validation cohorts, each answering a distinct diagnostic question. We benchmark five LLMs on eight PennyLane QHack challenges and ten Qiskit HumanEval tasks. Generated suites almost always execute, but discrimination lags behind: the best generator reaches a test quality of 0.71 on QHack and 0.34 on Qiskit HumanEval, so executability alone overstates test quality. 2. RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics

As AI agents increasingly rely on external tools, accurate retrieval is essential for reliable behavior. Existing methods optimize semantic relevance but largely ignore tool availability during execution. To address this gap, we propose RATED (Reliability-Aware Tool Retrieval via Execution Dynamics), a retrieval framework that combines robust semantic matching with dynamic reliability adaptation. RATED employs a frozen dual-encoder with contrastive fine-tuning for semantic matching, and a lightweight contextual bandit module that re-ranks candidates based on real-time execution feedback. This design enables rapid adaptation to runtime tool failures without expensive model retraining. We introduce EcoAgent, a benchmark of 5,172 real-world tools and over 210,000 query-tool pairs for offline retrieval and dynamic reliability evaluation. Experimental results demonstrate that RATED achieves a 52.2% relative MRR improvement over the ToolLLM API retriever on real-world queries, and reduces fault selection rate from 86.2% to 2.9% under severe API outage scenarios with a 30% failure rate, while incurring negligible latency overhead of less than 1 ms over encode-only inference. The code and dataset are available at https://github.com/Elliotes/EcoAgent.

3. When VLMs Destroy What They Know: Spatial Representations Fall Below Lexical Priors

Vision-Language Models (VLMs) increasingly analyze and reason about images, yet it remains unclear whether their internal representations faithfully encode the structured relations required for such reasoning. We introduce EICS (Evaluation-Invariant Concept Stability), a metric for testing whether representations consistently encode concepts under controlled one-concept interventions, and CASP-VL (Causally controlled Spatial Perturbations for Vision-Language models), a benchmark of causally controlled spatial perturbations derived from Visual Genome scene graphs. Across multiple VLM architectures, we find that spatial relations are represented substantially less faithfully than lexical information, even when the same models score well above chance on compositional benchmarks. Further analysis shows that the relation is identifiable at the predicate's own tokens but is lost when the sentence is aggregated into a global representation, whether through the (EOS) token or by mean pooling. These findings reveal a systematic failure invisible to output-based evaluation: VLMs do not preserve, in the representation used downstream, relational information that is present in their own input.

4. Task Context Shapes Component Roles in Language Models

A natural source of inspiration is task-dependent interactions among shared brain regions, which motivate a network view of language-model computation. Here, we compare fixed model components across tasks using identical graph facts, statements specifying which directed connections are present. We measure how interventions affect attention heads and the activation state in later layers (influence), as well as the answer (importance). Task changes redistribute the influence in five open-weight models spanning four families and 1.5-14 billion parameters. In Gemma-2-9B and Qwen3-14B, an activation edit changes an early internal activation vector and switches which fact the model reads while the written instruction stays fixed. 5. Tracing and Taming Hallucinated Terms via Subsequence-Association Filtering and Breadth-Aware Selection for LLM Query Expansion

Large language models (LLMs) are now a standard source of query expansion terms but they hallucinate. They inject non existent entities and off-topic terms that add ranking noise and can hurt strong retrievers. Existing remedies such as corpus grounding, mutual verification and preference alignment treat hallucinated terms as an undifferentiated nuisance to be filtered by agreement heuristics, without a mechanistic account of why a given term appears or a principled criterion for how many terms to keep. We propose Subsequence-Association Filtered, breadth-aware query expansion (SAFE-QE), a training-free, retriever agnostic method that draws on the subsequence-association account of hallucination. We score each candidate expansion term by its corpus conditioned cross-context reproducibility, terms that reappear under randomised query contexts yet lack support in the pseudo-relevant set are flagged as products of dominant hallucinatory associations and down-weighted. 👀 Watchlist

Persistent agent memory and cross-session context layers — claude-mem and hermes-agent both point to the same idea: agents that grow with you by turning memory from disposable context into an accumulating asset. Whoever makes memory reliable, portable, and auditable first will own long-horizon task workloads — the key blocker between agent demos and production deployment.
Chinese open models as the default local inference stack — Ollama's same-day push for Kimi, GLM, MiniMax, and DeepSeek shows Chinese models have moved from optional extras to first-class citizens in overseas developer tooling. This will reshape model selection, inference economics, and regional compliance, so download and downstream-integration data are worth tracking.
Reliability evaluation for agent tool retrieval — RATED proposes reliability-aware tool retrieval driven by execution dynamics, targeting the frequent failure mode of agents picking the wrong tool or calling it badly in crowded environments. As tool counts explode, retrieval quality will matter more than raw model capability in determining task success, making benchmarks and engineering practices here worth close attention.
Spatial representation collapse in multimodal models — Research shows VLM spatial representations can fall below lexical priors, suggesting visual ability is being overridden by language priors. That is a direct risk for robotics, autonomous driving, and industrial inspection, and may explain why multimodal products underperform in real-world settings.
The race for the personal AI agent entry point — Meta's Muse success has pushed ByteDance and Tencent to accelerate personal agents, StepFun's Step 5 Preview has landed inside Tencent WorkBuddy, and Microsoft is building decision models on Alibaba's Qwen with plans for domain-wide rollout. 1. QTestBench：以独立检查器评估LLM生成的量子测试套件

量子程序具有概率性、依赖数值容差、且由领域专用检查器判定，因此形式合规的测试仍可能与基准结论相左，而现有量子基准只衡量模型能否产出正确解，不衡量其测试能否区分正确实现与错误实现。作者为此提出 QTestBench：对每个任务提示模型生成语法、语义与行为三类测试，在运行时注入候选解，并在三个验证队列下把每条测试的判定与独立检查器标签逐一比对，测试本身从不被当作真值。该框架在 8 个 PennyLane QHack 挑战与 10 个 Qiskit HumanEval 任务上评测了 5 个 LLM，结果显示生成的测试套件几乎总能执行，但区分度明显滞后——最佳生成器在 QHack 上测试质量仅 0.71，在 Qiskit HumanEval 上低至 0.34，说明可执行性会高估测试质量。当自然错误解稀缺时（10 个 Qiskit 任务中有 3 个没有产生任何自然错误解），经 oracle 验证的合成变异体可稳定 bug 检测估计（该工作为 6 位作者的顶会录用论文）。这也意味着量子 LLM 代码生成的评测口径正从单一通过率，转向由领域检查器、概率性断言与容差驱动的验证。

## AI 学术研究

### 1. QTestBench：以独立检查器评估LLM生成的量子测试套件

量子程序具有概率性、依赖数值容差、且由领域专用检查器判定，因此形式合规的测试仍可能与基准结论相左，而现有量子基准只衡量模型能否产出正确解，不衡量其测试能否区分正确实现与错误实现。作者为此提出 QTestBench：对每个任务提示模型生成语法、语义与行为三类测试，在运行时注入候选解，并在三个验证队列下把每条测试的判定与独立检查器标签逐一比对，测试本身从不被当作真值。该框架在 8 个 PennyLane QHack 挑战与 10 个 Qiskit HumanEval 任务上评测了 5 个 LLM，结果显示生成的测试套件几乎总能执行，但区分度明显滞后——最佳生成器在 QHack 上测试质量仅 0.71，在 Qiskit HumanEval 上低至 0.34，说明可执行性会高估测试质量。当自然错误解稀缺时（10 个 Qiskit 任务中有 3 个没有产生任何自然错误解），经 oracle 验证的合成变异体可稳定 bug 检测估计（该工作为 6 位作者的顶会录用论文）。这也意味着量子 LLM 代码生成的评测口径正从单一通过率，转向由领域检查器、概率性断言与容差驱动的验证。

### 2. RATED 用执行反馈重排工具检索，故障选择率降至 2.9%

现有 Agent 工具检索方法普遍只优化语义相关性，基本忽略执行阶段工具是否可用。为此作者提出 RATED：以冻结双编码器加对比微调做语义匹配，再用轻量 contextual bandit 模块依据实时执行反馈重排候选工具，无需昂贵重训练即可适应运行时故障。配套基准 EcoAgent 含 5,172 个真实工具与逾 210,000 条查询-工具对，支持离线检索与动态可靠性评估。实验显示，RATED 在真实查询上相对 ToolLLM API retriever 的 MRR 提升 52.2%；在 30% 失败率的严重 API 故障场景下，故障选择率从 86.2% 降至 2.9%，而相比仅编码推理的额外延迟不足 1 ms。代码与数据集已在 GitHub 公开，论文获 CIKM 2026 录用。这意味着 Agent 工具检索开始把执行遥测与失败反馈纳入检索闭环，从单一语义排序转向语义与运行时可靠性的双目标排序。

### 3. When VLMs Destroy What They Know: Spatial Representations Fall Below Lexical Priors

视觉-语言模型（VLM）正越来越多地承担图像分析与推理任务，但其内部表征是否忠实编码了这类推理所需的结构化关系，仍不明确。论文提出 EICS（Evaluation-Invariant Concept Stability）指标，用于在受控的单概念干预下检验表征能否一致地编码概念；并构建 CASP-VL 基准，其因果控制的空间扰动取自 Visual Genome 场景图（该工作由2位作者完成）。在多种 VLM 架构上，空间关系的表征忠实度明显低于词法信息，即便这些模型在组合式基准上的得分已显著高于随机水平。进一步分析显示，关系信息在谓词自身的 token 上可被识别，但一旦句子被聚合为全局表征——无论经由 EOS token 还是平均池化——该信息即告丢失。这意味着模型可能在输出层面答对，却未在下游实际使用的表征中保留其输入本身已含有的关系信息，而这种失效无法被基于输出的评测发现，对机器人、具身智能、医学影像与图表问答等依赖精确空间关系的场景尤为关键。

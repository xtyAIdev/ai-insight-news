## AI 学术研究

### 1. 1.5B模型LoRA微调可检出胸片报告与图像证据不一致

Rad-Linter 先用预训练图像分类器为九类病理打分，再由一个经 LoRA 在 1,816 个样本上微调的 1.5B 参数语言模型判断这些图像证据与胸片报告是否一致，从而标记出可疑错误，供人工复核。研究以关键词加否定判断的规则方法作为基线对照；该研究用 OpenI 构造受控反事实四元组：每组的两个真实报告与来自其他患者的两份真实分数向量交叉组合，得到两对一致、两对不一致的配对，且每个报告与每个分数向量都会在两种条件下出现，因此单看任一输入最高只能达到 50% 准确率。在 131 个四元组上，Rad-Linter 的配对准确率为 98.5%，规则基线为 80.5%；四对全部判对的比例为 94.4%，规则基线为 56.5%。在涉及未提及和否定发现的省略项上，两者表现接近；差异主要出现在需要理解发现如何描述的其余项类型上。同一语言模型不做微调时，准确率仍停留在 50% 附近；在另外 181 个纳入自动标注器分歧报告的四元组上，配对准确率为 93.4%，规则基线为 75.3%。这意味着放射报告质控的核查对象，可能从纯文本规则转向报告与图像证据的一致性；不过该研究短期仍把它定位为辅助标记，而不是自动修改报告。

**时间**：2026-11-19

**标签**：cs.CL

**入选理由**：该论文仅由3位作者完成，把大语言模型用于胸片报告的多模态错误检测，强调模型需读取图像证据作判断，指向放射报告质控这一可落地场景，显示多模态校验正从研究走向临床文档把关。

**来源**：[arXiv](https://arxiv.org/abs/2611.26492v1)

### 2. MemFolder用结构引导折叠兼顾智能体记忆保真与效率

长期智能体在交互中积累大量外部记忆，存储、检索和响应生成成本会随记录数与检索上下文长度同时上升；剪枝可能丢弃有用证据，合并又可能产生更少但更长的检索单元。由9位作者完成的论文提出MemFolder，这是一个结构引导的记忆折叠框架，按顺序压缩记录数与上下文长度，两个核心组件共享记忆组，并利用跨记录结构指导证据合并与紧凑表示。RecordFolder对实体提及做grounding，逐步选择有代表性且互补的锚点，结合语义与实体亲和度及时间链，将兼容记录合并为更少检索单元；ContextFolder把组内原始记录编码为紧凑文本，并在关键事实无法恢复时用验证反馈修正编码。在LoCoMo、PersonaMem、LongMemEval三个文本记忆基准和M3-Bench-web、M3-Bench-robot两个多模态基准上，实验显示该方法性能较强；在Mem0上，RecordFolder在三个文本基准上保留了原始平均性能的99.0%。这指向长期智能体记忆管理从粗粒度剪枝或摘要转向结构感知的压缩与分层组织，若落地，记忆检索、上下文构造与推理成本可能被一起重新优化。

> *MemFolder的关键不是单纯把记忆压短，而是用跨记录结构判断哪些证据可折叠、哪些必须保留；若验证反馈能稳定兜住关键事实，记忆模块会更像可计算的索引结构，而不是单纯向量库或对话日志。*

**时间**：2026-11-19

**标签**：cs.CL

**入选理由**：该论文提出结构引导的记忆折叠方法，聚焦智能体记忆管理效率，由9位作者合作完成，指向Agent记忆压缩与效率优化的行业趋势。

**来源**：[arXiv](https://arxiv.org/abs/2611.26427v1)

### 3. HiSA 把注意力稀疏化搬到隐藏维度，点积只算三分之一仍胜过全量

HiSA（Hidden Sparse Attention）针对 LLM 注意力中每个 query 都要与每个 key 做完整点积的做法，保留 query 与 key 投影不变，只计算部分点积；其稀疏发生在隐藏（特征）维度，而非几乎所有稀疏注意力方法所针对的 token 维，且裁剪规则由 token 位置静态决定、不含可学习参数。作者依据 RoPE 的结构把 key 和 query 拆成可在注意力计算时省略的部分，并从零训练 LLM，结果显示这种部分点积只计算约三分之一的 query-key 乘积，性能不降反升。推理阶段 HiSA 提升解码速度并压缩显存占用，作者还把方案扩展到 FlashAttention-3 kernel，覆盖训练与推理。论文给出的动机分析是：稠密注意力在训练中本身就会学着抑制 HiSA 所丢弃的那部分注意力分数；代码已在 github.com/ambroise-b/hisa 开源。这意味着注意力效率优化可以从 token 级稀疏走向更细粒度的特征维结构化稀疏，为削减 LLM 注意力计算量提供一条与 token 稀疏正交、且不增加学习参数的新路径。

> *把稀疏对象从 token 对挪到隐藏维，等于在不改动投影的前提下对点积做静态裁剪，若在更大模型和更长上下文上精度依然稳定，注意力内核的设计空间可能被重新划分。而“稠密注意力本就在抑制被丢弃的分数”这一观察，暗示现有注意力的冗余粒度比 token 稀疏假设更细。*

**时间**：2026-11-19

**标签**：cs.LG

**入选理由**：综合评分 3.6论文数据：作者数=3

**来源**：[arXiv](https://arxiv.org/abs/2611.26363v1)

### 5. RL Post-Training in Diffusion Transformers Is Activation Steering

强化学习后训练能显著提升扩散 Transformer 的视觉质量、文字渲染与组合准确率，由于这些能力本身依赖提示词，通常被假设需要学习复杂的输入相关变换。为量化其中有多少收益可被一个与输入无关的平移解释，作者用极简参数化方式探测各 RL 模型：在冻结基座的 block 输出上加一组固定 steering 向量；在 SD3.5-M 上这组向量仅 0.29M 参数，比 RL 微调的 LoRA（18.8M）少 65 倍。这些向量通过拟合公开 RL checkpoint 的速度预测得到，目标函数中不含奖励，且对每个提示词、token 和采样种子完全相同，却能复现六个 RL 图像模型 90.0–96.3% 的奖励增益，并在两个 RL 视频模型上分别达到 89.8% 和 111.9%。以零初始化并用在线 RL 训练时，仅靠这组向量在 SD3.5-M 的文字渲染（OCR）与人类偏好（PickScore）上就超过了基于权重更新的 RL 增益。结论是：一个恒定偏移足以解释策略梯度式 RL 后训练的大部分收益——它并未学到新的输入相关变换，而是把预训练生成器导向其本已具备的能力；这也意味着部分后训练收益可能只是全局表征或激活被重新校准，而非新能力被学会。

> *若一组与输入无关的固定向量就能复现绝大部分 RL 增益，后训练的成本结构与可解释性叙事都要重估：对齐更接近“校准激活”而非“教会新技能”。由此推理，推理时的 steering 干预或许能替代一部分昂贵的策略梯度训练，但其在更复杂提示与安全对齐场景下是否同样成立，仍待验证。*

**时间**：2026-11-19

**标签**：cs.CV

**入选理由**：这篇6作者论文把扩散Transformer的RL后训练表述为激活引导，为DiT后训练提供了一条可解释的机制视角。

**来源**：[arXiv](https://arxiv.org/abs/2611.26627v1)
